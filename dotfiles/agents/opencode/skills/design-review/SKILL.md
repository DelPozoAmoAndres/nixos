## What I do
- Review designs for visual quality and consistency
- Check UI implementations against design specs
- Identify potential improvements and issues
- Provide actionable feedback

## When to use me
Use this skill when reviewing designs or UI code.

## Review Checklist

### Visual Quality
- [ ] Consistent spacing and alignment
- [ ] Proper color usage and contrast
- [ ] Typography hierarchy is clear
- [ ] Visual balance and composition
- [ ] Responsive considerations

### Technical Quality
- [ ] Components are reusable
- [ ] Naming is consistent
- [ ] Accessibility considerations
- [ ] Performance implications
- [ ] Cross-browser/device compatibility

### Design System Compliance
- [ ] Follows established patterns
- [ ] Uses existing components when possible
- [ ] Maintains consistency with existing UI

## Output Format
For each issue found:
1. **What**: Description of the issue
2. **Where**: Exact location
3. **Why it matters**: Impact on user experience
4. **Suggestion**: How to fix it
5. **Priority**: Critical / High / Medium / Low

## Rules
- Be constructive, not just critical
- Prioritize issues by impact
- Always suggest solutions, not just problems
- Consider the user's perspective
